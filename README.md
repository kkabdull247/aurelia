- localStorage demo cart
- Front-end demo forms for reservations, catering, checkout, login and registration

## Important
Payment processing, real customer authentication, hotel inventory, reservation availability and production form delivery need to be connected to the client's actual services before launch.


## GitHub upload
All files are intentionally stored in this single directory. No subfolders are required. Local page, image, CSS, JS, font and data references have been rewritten for the flat layout.
